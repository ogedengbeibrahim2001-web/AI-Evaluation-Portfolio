# Project 01: LLM Response Quality Evaluation (`Q01`–`Q20`)

Comparative evaluation of **ChatGPT** and **Claude** across 20 prompts (`Q01`–`Q20`) scored on five criteria (**Accuracy**, **Relevance**, **Completeness**, **Instruction Following**, and **Clarity**) from **1 to 5** (**25 points max per prompt**, **500 points total**).

## Headline Results
* **Claude:** `491 / 500` (`98.2%`) — **7 prompt wins** (`Q08`, `Q10`, `Q11`, `Q13`, `Q14`, `Q15`, `Q16`)
* **ChatGPT:** `483 / 500` (`96.6%`) — **2 prompt wins** (`Q05`, `Q06`)
* **Ties:** `11` prompts (`Q01`–`Q04`, `Q07`, `Q09`, `Q12`, `Q17`–`Q20`)

## Files in This Folder
* `evaluation-dataset.csv` — Prompt suite (`Q01`–`Q20`) and categories
* `evaluation-rubric.md` — Scoring definitions and scale criteria
* `data/evaluation-results.csv` — Per-criterion scores, totals (`Q01`–`Q20`), winners, and evaluator notes
